# Resources

Place the following icon files here:

- `icon.ico` — Windows application icon (256x256, 128x128, 64x64, 48x48, 32x32, 16x16)
- `icon.icns` — macOS application icon
- `icon.png` — Linux icon (256x256 or 512x512)

The icon should be a stylized 3×3 grid (representing SMX pad panels) with colored LED dots and a pencil/brush overlay.
